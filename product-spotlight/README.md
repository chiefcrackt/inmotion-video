# T.im Product Spotlight

18 independent overlay designs: six product labels, six feature callouts and
six experience cards. Navy, gold and teal. No product photos are required.

Blank PNG/SVG downloads have no baked-in text. Ready-to-edit Asset Animator
projects provide product-name and note placeholders as separate text layers.
Template previews are explicitly examples; they contain placeholder wording.
The catalog's Edit this template links and Asset Animator's template selector
use trusted template IDs. Replacing an existing composition asks first.

Edit `assets.mjs` and `templates.mjs`, then run `npm run build:product-spotlight`.
The build uses Chromium/Chrome/Edge to rasterize SVGs and the actual Asset
Animator renderer and fonts to generate preview images. Generated files are
committed so GitHub Pages has no runtime build dependency.

The ZIP includes 18 blank PNGs, 18 composed SVGs, 46 aligned PNG/SVG parts,
18 editable JSON projects, 18 example previews, a contact sheet, manifest and
usage guide. SVGs and projects are also individually downloadable.

Run `npm run test:product-spotlight` to check all projects, text safety, template
loading and editing, transparency, downloads, navigation and mobile layouts.
