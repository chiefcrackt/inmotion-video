# Weird Motion

Twenty original T.im vector motion toys in the suite's navy, gold and teal. Each toy has two actions.

| Stopwatch | Tick + reset | Personal best |

| Finisher medal | Spin + shine | Ribbon drop |

Each toy comes as a full callout version and a standalone version without the panel. Both are in Asset Animator's Weird Motion pack. Full callout templates add independent editable text. Actions use the layer's start delay and entrance duration, then hold their final pose. All composition exit options remain available.

`artwork.mjs` produces the same vector commands for SVG downloads and direct canvas animation. It uses no external images, random state, timers, or per-frame image decoding. Preview, seeking and both video export paths share the renderer. Still PNGs use the completed SVG artwork.

## Commands

- `npm run test:weird-motion` runs the unit checks and the browser test.
- `npm run build:weird-motion -- <output-directory>` packages blank SVG/PNG graphics, editable JSON projects and an offline interactive preview.

The JSON projects and online builder links require this version of Asset Animator. PNG and SVG downloads are static; export animated clips through the builder.
