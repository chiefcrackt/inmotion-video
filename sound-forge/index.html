03 / Advanced · Four-layer mixer

Select a track to edit. Start and duration controls provide precise timing on touch devices. Waves include effects tails; muted tracks appear dimmed.

Sample pitch changes playback rate and audible length; it does not preserve time. Duration is the output window, and trim selects the starting point in the original sample. Reverse flips that window before effects.
