Video Tagger

Go through a whole folder of footage on your PC: transcribe every video, tag it and describe it, all saved in one library.json.

Computer only — local launcher required

This tool does not work on phones or tablets. It runs on the Windows computer with Transcribe Video and Ollama installed.

Computer only

Start Video Tagger

  1. On your Windows computer, open the repo’s local-tagger folder and double-click Start Video Tagger.cmd, or use the button below to copy the command.
  2. Pick a folder of videos. Subfolders are included.
  3. Leave the window open while it works. It shows each video and step, then a summary.

Run it again any time: videos already in the library and unchanged are skipped, and a stopped run carries on where it left off.

What you get for each video

  • DetailsLength, vertical / horizontal / square, resolution, frame rate and recorded date.
  • TranscriptTXT, SRT and word-timing JSON from the Transcribe Video engine on your GPU.
  • Speech levelNone, little or lots, so B-roll and trail footage are easy to find.
  • TagsOnly from your tag list. Anything else becomes “other” with a suggested label.
  • DescriptionOne or two plain sentences: what’s said, then what’s on screen.
  • Needs reviewFlagged when the model is unsure, with the reason.

Your tags

Edit D:\VideoTagger\tags.json to change the list. The starting tags:

  • trail review
  • race
  • training run
  • long run
  • workout
  • strength
  • gear
  • food & fueling
  • Hooper
  • RRC / run club
  • talking to camera
  • B-roll
  • scenery
  • aid station / crew
  • travel
  • other

Your videos are only read, never changed or moved. Transcription uses the same engine as Transcribe Video, and tags come from a local Ollama model that looks at the transcript and a few frames. Nothing is uploaded and no paid API is used. Results go to D:\VideoTagger.
