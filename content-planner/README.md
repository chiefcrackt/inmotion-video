# Content Planner and Shoot Planner

Open Content Planner from T.IM Studio. Move videos through Idea, Outline, Film, Edit, Scheduled and Published using the Stage field or desktop drag and drop. Each video has an outline, film/publish dates and tool snapshots. Plans sync to Content Studio when signed in. Footage and thumbnail links are kept on this device only. Start from Idea Vault copies a local idea without editing it; repeating opens the existing project.

Outline lines become talking points. Prefix lines with B-roll:, Gear: or Location: to classify them. Generation is additive and keeps capture status and take notes. Paste outline text to generate a checklist. Filming mode shows one item at a time with captured, retake and skip controls.

## Verification

Run npm run test:planner. npm test includes the planner unit tests.
